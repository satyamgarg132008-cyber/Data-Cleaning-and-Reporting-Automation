# Data Cleaning & Reporting Automation

## Objective
To automate data cleaning and reporting workflows using Python.

## Features
- Missing Value Handling
- Duplicate Removal
- Automated Report Generation
- Visual Summaries
- Export of Cleaned Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Workflow
1. Load Dataset
2. Identify Missing Values
3. Clean Data
4. Remove Duplicates
5. Generate Automated Report
6. Create Visual Summaries
7. Export Clean Dataset

## Output Files
- automation_report.csv
- cleaned_dataset.csv

## Conclusion
The project successfully automated data cleaning and reporting tasks, improving efficiency and reducing manual effort.
